# Zarka – Tailoring Services Platform

Zarka is a Flutter-based tailoring services platform developed for SewCode Technologies, architected using Domain-Driven Design (DDD) for clean scalability and modularity. Inspired by Zomato’s service flow, Zarka connects users with skilled and verified tailors, enabling them to browse tailor profiles, explore service offerings, view past work, check delivery timelines, and place custom stitching orders. Tailors can manage orders, respond to client requests, and showcase their craft through an intuitive dashboard. With a modern, mobile-first interface and real-time interaction features, Zarka aims to digitize and streamline the custom tailoring experience, bridging the gap between craftsmanship and convenience.
